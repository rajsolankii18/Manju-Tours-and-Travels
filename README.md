# Manjushree Tours and Travels website

A simple responsive website for travel enquiries in Jodhpur.

## Hostinger deployment

Import the Git repository in Hostinger. The included `package.json` has a valid `start` script for a normal import. You can also choose **Deploy as static** because the repository root contains `index.html` and requires no build command.

## Local preview

```powershell
npm start
```

Open `http://127.0.0.1:3000`.

## Content notes

- Only ordinary public business contact and service information is included.
- Website photographs are AI-generated representative visuals, not documentary photographs of actual premises or customers.
- Travel services, providers, fares, inclusions, availability and cancellation conditions must be confirmed directly with the business.
